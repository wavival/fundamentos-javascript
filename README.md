## Para quién es

Personas que empiezan con JavaScript o quieren reforzar las bases del lenguaje, con ejemplos y práctica pensados para entenderlo y no solo repetirlo.

## Qué vas a aprender

- El lenguaje base: variables, tipos, funciones, estructuras de datos y control de flujo.
- Cómo funciona por dentro: scope, closures, call stack, event loop y memoria.
- Asincronismo, DOM y APIs del navegador.
- Orientación a objetos, módulos, programación funcional y JavaScript moderno.
- Node.js, testing, patrones de diseño, rendimiento y seguridad.
